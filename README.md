# 🎬 CineVerse

CineVerse is a simple and attractive movie search and watchlist web application built using HTML, CSS, JavaScript, and Bootstrap. It allows users to search for movies and save their favorites to a personal watchlist.

---

## 🚀 Features

- 🔍 Search movies by name  
- 🖼️ View movie poster, title, and year  
- ⭐ Add movies to a watchlist  
- 📋 View and manage your watchlist  
- 🎨 Clean and responsive UI using Bootstrap  
- ⚡ Fast movie data using OMDb API  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Bootstrap 5  
- OMDb API  

---

## ▶️ How to Run

1. Clone or download this repository.
2. Open `search.html` in your browser.
3. Start searching for your favorite movies!
